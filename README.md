# GrapeClip Releases

[GrapeClip](https://grapeclip.com) 是一款端到端加密的跨平台剪贴板同步工具，支持 macOS、Windows、Linux 与 Android。

本仓库只用于发布安装包和收集反馈。GrapeClip 目前处于内测阶段，源代码暂不公开。

## 下载

- 所有平台的安装包：[Releases](https://github.com/einverne/grapeclip-releases/releases)
- macOS 也可以用 Homebrew 安装：

  ```bash
  brew install --cask einverne/tap/grapeclip@beta
  ```

内测期间发布的都是预发布版本（tag 带 `-rc` / `-beta` 后缀），桌面端内置自动更新。

## 反馈

遇到问题或有建议，欢迎提 [Issue](https://github.com/einverne/grapeclip-releases/issues)。
